# my-language

The LangServe app (`app/server.py`) that serves the `my-assistant` chain at `/assistant`, with an interactive playground at http://localhost:8000/assistant/playground/.

Dependencies, setup and how to add more chains are in the [main README](../README.md). Start it with `./run.sh` from the repo root, or `langchain serve` from this folder with the venv active.
